**FinanceFlow** — это мощный Telegram-бот для мониторинга курсов валют в реальном времени. Проект демонстрирует работу с внешними API, асинхронными базами данных и современной системой оплаты цифровых товаров Telegram Stars.

---

## ✨ Основные функции

- **Актуальные курсы:** Интеграция с [ExchangeRate-API](https://www.exchangerate-api.com/) для получения данных по 150+ валютам.
- **Умное кеширование:** Снижение нагрузки на API и мгновенный ответ пользователю за счет кеширования курсов в SQLite (обновление раз в час).
- **Premium подписка (XTR):** Реализованная система монетизации через Telegram Stars. Подписка открывает доступ к дополнительным валютам (JPY, CNY и др.).
- **Многопользовательская БД:** Автоматическая регистрация пользователей и хранение статуса подписки.
- **Оптимизированный код:** Использование рефакторинга для минимизации дублирования логики (DRY).

---

## 🛠 Стек технологий

- **Backend:** Python 3.10+
- **Framework:** [aiogram 3.x](https://docs.aiogram.dev/)
- **Database:** [aiosqlite](https://github.com/omnilib/aiosqlite) (Asynchronous SQLite)
- **API Requests:** [aiohttp](https://docs.aiohttp.org/)
- **Payments:** Telegram Stars (XTR)
- **Data Format:** JSON
